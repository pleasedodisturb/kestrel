# Kestrel Illustrations

Brand illustrations for Kestrel - geometric kestrel falcon art in various styles.

## Credits

All illustrations generated with [Maginary AI](https://app.maginary.ai/) - a genuinely impressive image generation platform. Curated from 97 candidates down to 41 keepers.

## Usage

### Hero images (for doc headers, social preview, marketing)

| File | Style | Suggested use |
|------|-------|---------------|
| `hero-navy.webp` | Navy/orange/gold, retro grain | README header, GitHub social preview |
| `hero-coral.webp` | Red coral, art deco dive | QUICKSTART.md, PyPI page |
| `hero-yellow.webp` | Yellow/blue, bold geometric | FAQ.md, app loading screen |
| `hero-sky.webp` | Yellow/blue/orange, spread wings | COMPARISON.md, blog posts |
| `hero-bauhaus.webp` | Green/orange/black, Bauhaus | CONTRIBUTING.md, stickers |
| `hero-tropical.webp` | Green/yellow/blue, vivid | AI-PROVIDERS.md |
| `hero-vivid.webp` | Purple/pink/green, maximalist | Landing page |
| `hero-closeup.webp` | Navy/orange, close-up detail | HELP.md, error pages |

### Logo variants (for icons, favicons, avatars)

| File | Style | Suggested use |
|------|-------|---------------|
| `logo-icon.webp` | Angular geometric, dark navy/orange | Favicon, app icon, GitHub avatar |
| `logo-line.webp` | Minimal line art | Dark mode, watermark, monochrome |

### Gallery

The `gallery/` folder contains 31 additional curated illustrations in various styles - geometric, retro, Charley Harper-inspired, Bauhaus, line art, and low-poly. Free for use in blog posts, presentations, community materials, and merch.
