# Kestrel brand assets

Hand-authored SVG logo set for the Kestrel project. This is a v0.2 pass —
an improvement on the earlier "salmon era" logo but **not** a professional
brand asset. A real designer is still wanted on #79.

## Files

| File                  | Purpose                                            |
|-----------------------|----------------------------------------------------|
| `logo-icon.svg`       | Standalone falcon, transparent bg, 64×64 viewBox   |
| `logo-badge.svg`      | Falcon inside dark-navy circular badge (app icon)  |
| `logo-full.svg`       | Falcon + "KESTREL" wordmark + tagline (horizontal) |
| `logo-icon-dark.svg`  | Dark-background variant (amber outline)            |

## Palette

- `#D4572A` rusty orange — body, primary wing fill
- `#1E293B` dark navy slate — outline on light bg, badge background
- `#F5A623` amber gold — eye iris, outline on dark bg

## Design intent

Stooping-dive falcon silhouette. Iconic raptor cues:

- Clearly hooked beak (not a rounded fish snout)
- Eye positioned behind the beak, amber with navy pupil
- Long wings swept up-back, not rounded fins
- Compact teardrop body with split tail feathers

All four variants share the same path geometry so they read consistently
at favicon size (16×16) through hero-image scale.
