# Repo Coaching

A masterlist + audit + form-factor recommendation for taking a public GitHub repo from "exists" to "thriving."

## Files in this folder

| File | What it is |
|---|---|
| [`MASTERLIST.md`](./MASTERLIST.md) | The big checklist — three layers (Technical, Operational, Marketing/Branding), ~200 items |
| [`LANDSCAPE.md`](./LANDSCAPE.md) | What already exists in the repo-coaching / repo-auditing space, with a gap analysis |
| [`AUDIT.md`](./AUDIT.md) | Kestrel-specific audit against the masterlist — what's good, what's missing, prioritized |
| [`FORM-FACTOR.md`](./FORM-FACTOR.md) | Recommendation: should this be a one-off audit, an awesome-list, or an AI bot? |

## How to use it

1. Read `MASTERLIST.md` end-to-end once. Mark items that are obviously irrelevant.
2. Read `AUDIT.md` for the Kestrel-specific snapshot.
3. Read `FORM-FACTOR.md` for what to build next.
4. If you want to scale this beyond Kestrel, `LANDSCAPE.md` shows where the gaps are.

## Source quality note

Two sources of input fed this:
- High-signal docs (GitHub, OpenSSF, OSS guides, well-known maintainers' writing).
- Live web searches done in May 2026 — links cited inline in each doc.

This is not a survey paper. It's an opinionated coaching system built to be acted on.
