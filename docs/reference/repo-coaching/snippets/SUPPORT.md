# How to get help

## Bugs / feature requests
[Open an issue](https://github.com/OWNER/REPO/issues/new/choose) using one of the templates.

## Questions / discussion
[GitHub Discussions](https://github.com/OWNER/REPO/discussions) — fastest answer for "how do I..."

## Real-time chat
[Discord](https://discord.gg/INVITE) — community help, not for guaranteed maintainer response.

## Commercial support
Not currently offered. Sponsor via [GitHub Sponsors](https://github.com/sponsors/OWNER) for prioritized help.

## Security issues
**Do not open a public issue.** See [SECURITY.md](./SECURITY.md).
