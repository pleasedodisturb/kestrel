## Git delivery (binding, identical in every Phase 11 plan)

1. **Branch.** Every Kestrel deliverable lands on `G-2039/map`, cut from `origin/main` (main tip when planned: `21ac4b0d`). Never base work on `G-2013/v2-lean-milestone`: most of its commits carry no `Reviewed-by` trailer, and the `Review trailers` CI job checks every commit in the PR range.
2. **Pre-execution step (orchestrator or maintainer, once, before `/gsd-execute-phase 11`).** In the main checkout, after these plans are committed on the milestone branch: `git fetch origin main`; `git switch -c G-2039/map origin/main`; `git restore --source=G-2013/v2-lean-milestone -- .planning/`; one commit `docs(G-2039): carry the v2.0 planning docs onto the Map branch` whose body says why one reviewed commit replaces the unsigned milestone history; `review-push run`, answer findings, `review-push sign`, `git push -u origin G-2039/map`. Execute-phase then runs from this checkout, so executor worktrees (`worktree.baseRef: head`) fork from `G-2039/map` and land back on it. This is the default for open question OQ-3.
3. **Commits.** Conventional, scoped to the ticket, each with a body saying what changed and why: `test(G-2039): ...` for goldens, mapping tables, ledger tests, MAP-05 and the marker; `docs(G-2039): ...` for ledger data, counts and the verdict list. End each message with the attribution lines the session supplies.
4. **Staging.** Stage by explicit path only. The checkout carries untracked folders (`.planning/research/.cache/`, `.gsd/`, older quick-task folders) that main's `.gitignore` does not cover; they must never be committed.
5. **Push.** Before every push of `G-2039/map`: `review-push run`, answer every medium+ finding (`review-push disposition {id} rejected --reason ...`, or fix and run again), `review-push sign`, `git push`. Never amend after signing without a fresh run; rebase, never merge main in. When this plan ran in an isolated executor worktree, the orchestrator does this after landing the plan's commits on `G-2039/map` by rebase or cherry-pick.
6. **PR.** One PR for the phase, opened by plan 11-06 after this plan has crossed the verdict list. The maintainer merges, only on green CI.

**Shell variables:** `MAP_PRIVATE_REPO` and `MAP_EXPORT` as defined in plan 11-04 (set at run time from the gitignored README, never written to Kestrel); cwd is the `G-2039/map` checkout root with the project environment active.
