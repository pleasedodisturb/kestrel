5. **Push.** Before every push of `G-2039/map`: `review-push run`, answer every medium+ finding (`review-push disposition {id} rejected --reason ...`, or fix and run again), `review-push sign`, `git push`. Never amend after signing without a fresh run; rebase, never merge main in. 6. **PR.** One PR for the phase, opened by plan 11-06 after plan 11-05 has crossed the verdict list. The maintainer merges, only on green CI.
