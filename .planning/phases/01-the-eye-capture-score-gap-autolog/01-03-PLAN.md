<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host job page DOM → content script | Page content is untrusted; the script only READS the DOM (extraction) and injects one button — never executes page-provided code |
| content script → background worker → backend | Capture only crosses the network via the worker (golden rule); content script never fetches the backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01C-01 | Tampering | Malicious JSON-LD / HTML in the page | mitigate | Defensive parse (try/catch, tag-strip to text); no innerHTML sink from page data; button rendered in a shadow root |
| T-01C-02 | Elevation | Over-broad host access | mitigate | Explicit `matches` allowlist + `activeTab` only; NO `<all_urls>`, no wildcard host_permissions (grep-gated) |
| T-01C-03 | Info-disclosure | Background crawl leaking browsing to backend | mitigate | Capture is user-click-only; no auto-fire on navigation; no telemetry |
| T-01-SC | Tampering | npm dependency changes | accept | No new runtime deps expected; if any added, run `npm audit signatures` and record in SUMMARY (else this line is N/A) |
</threat_model>
