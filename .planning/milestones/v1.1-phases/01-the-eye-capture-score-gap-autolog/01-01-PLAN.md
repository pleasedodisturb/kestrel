<objective>
Harden the Phase 0 pairing/token path BEFORE capture carries real profile data (CONTEXT Part A; SECURITY.md T-00-06, T-00-07, token-no-expiry — all explicitly deferred to G-1391). Three defenses, all file-based, NO Alembic migration:
1. Rate-limit `POST /api/extension/pair` to 5 attempts/min/IP (slowapi) → 429, killing the ~10⁶ brute-force on the 6-digit code.
2. Replace the always-valid time-windowed code with a single-use, user-initiated code minted on demand by `kestrel extension pair`, its hash+expiry persisted to `data/.extension_pairing` (0600, atomic — mirrors `.extension_secret`).
3. Add a token max-age check (default TTL 30 days, configurable `extension_token_ttl_days`) to `verify_extension_token`; expired → 401 "re-pair".

Purpose: Close the always-on guessing window and the unbounded-token lifetime before real data flows through capture. This plan is a BLOCKING prerequisite for 01-02 (Part B), which shares `api/extension.py` — hence 01-02 is wave 2.
Output: Hardened pairing service + route + CLI + full test coverage (429, single-use reuse rejected, expired token 401, valid flow intact).
</objective>

<design_decision>
LOCKED (CONTEXT flag confirmed by planner):
- Token TTL default **30 days**, configurable via new setting `extension_token_ttl_days`. The stateless token already embeds `issued_ts`; the check is `now - issued > ttl_days*86400 → invalid`. TTL ≤ 0 disables the check (escape hatch / tests).
- Single-use pairing nonce is **file-based** (`data/.extension_pairing`, 0600, atomic O_CREAT|O_EXCL), NOT a DB table — same rationale as `.extension_secret`: no migration on the just-reconciled in-package Alembic history (G-1350). Acceptable per CONTEXT.
- Revocation remains secret-rotation (documented); a persisted revocable store is a later upgrade.
</design_decision>

| Boundary | Description |

| stored extension token → `/capture`, `/status` | A minted token is a bearer credential to real profile data (once 01-02 lands) |

|-----------|----------|-----------|-------------|-----------------|
| T-01A-01 | Spoofing/Elevation | `/pair` brute-force of 6-digit code (SECURITY T-00-06) | mitigate | slowapi `@limiter.limit("5/minute")` per IP → 429; ~10⁶ space now takes >100 days at 5/min |
| T-01A-02 | Elevation | Always-on, always-valid time-windowed code | mitigate | Single-use nonce minted on demand, sha256+expiry in `data/.extension_pairing` (0600), consumed (deleted) on success |
